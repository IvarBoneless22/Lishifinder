# Lishi Finder

Статичний PWA-каталог сумісності автомобілів і відмичок Lishi. Застосунок не має бекенду чи залежностей: його можна відкрити локально або розмістити в корені GitHub Pages.

## Можливості

- три режими: пошук авто, пошук за кодом Lishi та порівняння джерел;
- фільтри за маркою, ринком, роком і типом ключа;
- локальні векторні значки марок у фільтрі, швидкому виборі та результатах;
- перегляд реального фото моделі після натискання на її назву;
- імпорт дозволених CSV/JSON для порівняння з вбудованим каталогом;
- власні примітки до кожного запису зі збереженням на пристрої;
- офлайн-режим після першого завантаження;
- позначення записів, які потребують перевірки або не мають підтвердженого коду;
- автоматична перевірка структури каталогу в GitHub Actions.

Фото завантажуються за запитом із Wikimedia Commons і потребують інтернету. У вікні фото показується авторство, ліцензія та посилання на сторінку оригіналу. Автоматичний пошук може підібрати інший рік або покоління, тому зображення також має довідковий характер.

## Порівняння та власні примітки

Режим «Порівняти» зіставляє записи LishiFinder з даними, які користувач імпортував із дозволеного CSV або JSON. Файл обробляється в браузері та зберігається у localStorage; на сервер він не надсилається. Шаблон міститься у `sample-external-data.csv`.

Підтримувані поля імпорту: `brand`, `model`, `years`, `yearFrom`, `yearTo`, `market`, `lishi`, `source`, `sourceUrl`, `note`. Обов’язковими є `brand`, `model` і `lishi`. Також розпізнаються поширені назви колонок `make`, `vehicle`, `tool`, `reference`, `keyway` та українські відповідники.

Примітки зберігаються локально для кожної комбінації автомобіля, років, ринку та Lishi. Кнопка «Експортувати мої дані» створює резервну JSON-копію імпортованих записів і приміток. Такий файл можна імпортувати назад.

LARA та інші платні бази не копіюються і не обходяться. Їхні записи можна додати лише через офіційно дозволений експорт або API.

## Відповідальне використання

Дані мають довідковий характер і не замінюють візуальну та технічну перевірку профілю ключа. Використовуйте застосунок лише під час законних робіт за наявності дозволу власника автомобіля.

## Дані каталогу

Файл data.js містить об’єкт window.LISHI_DATA з версією каталогу та записами такого формату:

- brand, model, years — відображувані дані автомобіля;
- yearFrom, yearTo — нормалізований діапазон для фільтра за роком;
- markets — масив нормалізованих кодів ринків;
- ignition — key, smart, prox або unknown;
- lishi — код Lishi для перевіреного запису;
- status — verified, needs_review або not_available;
- note — причина, чому запис не можна рекомендувати автоматично.

Перед зміною даних запустіть npm run validate. Перевірка також виконується автоматично для pull request та змін у main.

## Публікація

1. У GitHub відкрийте Settings → Pages.
2. Виберіть розгортання з гілки main, папка /(root).
3. Після публікації відкрийте адресу GitHub Pages.

Після оновлення сайту офлайн-користувачі можуть натиснути «Оновити офлайн-версію».
